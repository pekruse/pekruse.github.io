ESP32 Macro Controller

A browser-controlled macro interface built around an ESP32-S3, Wi-Fi, and USB HID. A practical exploration of turning a small microcontroller into a useful computer interface.

From browser tap to keyboard input

A local web interface sends a selected action over Wi-Fi to the ESP32-S3. The firmware maps that action to a USB HID keyboard input for the attached computer. The phone and computer interact with the same board through different interfaces.

Prototype question

How should the controller show whether the local web interface is reachable and whether the computer is ready to receive keyboard input?
