5G VTOL Drone

I’m modeling a one-meter tilt-rotor drone in Simulink. The design uses four tilting rotors for vertical takeoff and landing.

Flight controlsFocus
5GConnectivity
SimulinkModeling

How does the aircraft stay level as the rotors tilt?

I’m using the model to study the transition from hover to forward flight. I want to understand how rotor angle changes lift and how quickly the controller needs to respond.

Where 5G fits

I’m exploring 5G for telemetry. One design question is which data can tolerate a delayed connection and which control decisions need to stay onboard.
